법인카드 집근처 사용 분석

카드 이용내역과 임직원 집주소를 카카오지도로 대조해 집 근처 사용·휴일/심야 사용·분할 거래 의심 건을 예외 목록으로 만듭니다. 모든 처리는 이 브라우저 안에서만 이루어지고, 원본 파일은 읽기만 합니다.

1

카카오지도 연결

현재 접속 주소:
카카오 Web 플랫폼에 이 주소를 그대로 등록해야 합니다.
키를 입력하고 [연결 테스트]를 누르세요. 키 없이도 [샘플로 체험]으로 분석 화면은 볼 수 있습니다(지도 제외).
연결이 안 될 때 확인할 것
  1. 앱 설정 → 플랫폼 → Web에 접속 주소(예: http://localhost:5500)를 등록합니다.
  2. 앱 설정 → 제품 설정 → 카카오맵을 사용 설정 ON으로 바꿉니다. 꺼져 있으면 지도·검색이 모두 거부됩니다.
  3. REST API 키가 아니라 JavaScript 키를 입력합니다.
  4. 파일을 더블클릭(file://)으로 열면 도메인 등록이 안 되므로 로컬 서버 주소로 여세요.
2

분석 기준

법정 공휴일은 2025~2026년분이 내장되어 있습니다. 임시공휴일은 위 칸에 추가하고, 결과 후 정부 공고와 대조하세요.
AI

Gemini 연결 (이상징후 요약 · 경영진 보고서용, 선택)

키는 이 페이지 메모리에만 있고 저장되지 않습니다(새로고침하면 다시 입력). 요청은 브라우저에서 Google로 바로 전송됩니다.
키를 입력하고 [모델 불러오기·연결 테스트]를 누르세요.
⚠ AI 요약·보고서를 만들면 집계 수치와 상위 예외 거래(가맹점명·금액·일시·규칙)가 Google Gemini로 전송됩니다. 집주소·카드번호는 전송하지 않으며, 이용자명은 기본으로 가명(직원01…)으로 바꿔 보냅니다. 사내 정보 반출 기준을 확인한 뒤 사용하세요.
3

데이터 불러오기

① 법인카드 이용내역 (.xlsx / .xls / .csv)
열: 순번, 카드번호, 이용자명, 이용일, 가맹점명, 이용금액, 가맹점 주소, 사업자 등록번호, 승인번호, 과세유형, 전표구분, 미화금액, 미화환율, 승인시간, 가맹점업종코드, 가맹점업종명, 유종, 리터당단가
아직 불러온 파일이 없습니다.
② 임직원 집주소 (이용자명 → 집 주소)
카드 파일에는 집주소가 없어 별도 목록이 필요합니다. 파일을 올리거나 아래에 이름,주소 형식으로 한 줄씩 붙여넣으세요. 개인정보이므로 저장·전송되지 않습니다.
집주소가 없으면 분할 거래·휴일 사용 규칙만 적용됩니다.
주소 → 좌표 변환(지오코딩)을 거래처·집주소마다 1회 수행합니다. 거래처 좌표는 이 PC에 캐시되어 재분석이 빠릅니다.
4

분석 결과

카카오지도를 연결하면 지도가 표시됩니다.
남색 = 집, 붉은 점 = 반경 이내 사용처, 회색 = 그 밖. 표의 행을 누르면 해당 거래로 이동합니다.
