# 법인카드 집근처 사용 분석

`index.html` 하나로 동작합니다. 카카오지도 도메인 등록 때문에 더블클릭이 아니라 로컬 서버 주소로 여세요.

```bash
python -I -m http.server 5500 --bind 127.0.0.1
```
접속: `http://localhost:5500/card-nearhome/index.html`

## 카카오 설정 (1회)
1. developers.kakao.com → 내 애플리케이션 → 앱 키에서 **JavaScript 키** 확인
2. 플랫폼 → Web에 `http://localhost:5500` 등록
3. 제품 설정 → **카카오맵 사용 설정 ON**
4. 화면 1단계에 키 입력 → [연결 테스트] (또는 `.env`의 `KAKAO_JS_KEY` 불러오기)

## 입력
- 카드 이용내역: 이용자명·이용일·가맹점명·이용금액·가맹점 주소 필수, 나머지 열은 있으면 활용
- 임직원 집주소: `이름,주소` 목록(파일 또는 붙여넣기). 브라우저 밖으로 전송·저장되지 않음

## 규칙 (CLAUDE.md 판정 기준 반영)
N01 집 근처 / N02 집 근처+휴일 / N03 집 근처+심야 / N04 집 근처+개인성 업종 / S01 분할 거래(동일 거래처·동일일 2건 이상, 합산 > 전결한도 100만 원) / H01 휴일 사용 전건.
직선거리 기준이며 취소 전표·음수 금액은 제외합니다. 결과 엑셀은 예외마다 전표번호·금액·규칙ID·근거를 담고, 원본 파일은 수정하지 않습니다.

## AI 이상징후 요약 · 경영진 보고서 (Gemini)
- 화면의 **Gemini 연결** 카드에 API 키를 직접 입력합니다(저장되지 않음). `.env`의 `GEMINI_API_KEY` 불러오기도 가능합니다.
- 분석 후 **5단계**에서 [이상징후 요약] 또는 [경영진 보고서 작성]을 누릅니다. 결과는 복사, Word(.doc) 저장, 인쇄/PDF로 내보냅니다.
- 숫자는 프로그램이 먼저 집계해 Gemini에 넘기고, 보고서 끝에 **부록(시스템 집계)** 을 자동으로 붙여 AI 문장과 대조할 수 있게 합니다.
- 전송 범위: 집계 수치와 상위 예외 20건(가맹점명·금액·일시·규칙). **집주소·카드번호는 전송하지 않으며**, 이용자명은 기본으로 가명(직원01…) 처리합니다. 결과 화면에서만 실명 복원 가능합니다.
